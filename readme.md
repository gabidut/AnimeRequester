## 📌 Description



#### AnimeRequester est une application web permettant d'interroger une base de données d'animé 


## 🛠️ Technologies utilisées

- HTML 5
- CSS 3
- JavaScript Vanilla
- Anime DB API

## ✨ Fonctionnalités

#### La version 1 permet de :

- Rechercher un anime par son nom
- Rechercher un anime à partir de son identifiant
- Rechercher un anime à partir de son classement
- Afficher jusqu’à 10 résultats pour une recherche par nom

#### La version 2 ajoute des fonctionnalités de :

- Recherche par genre
- Responsivité
- Saisie de la clé API directement depuis l'interface
- Mode clair et mode sombre avec conservation du choix de l'utilisateur grâce à sessionStorage

## 🚀 Installation

Pour intaller AnimeRequester en Zip

1. [**Cliquez ici**](https://github.com/gabidut/AnimeRequester/archive/refs/heads/main.zip)
2. Clique droit sur le dossier
3. Extraire Tout
4. Ouvrez le dossier **"AnimeRequester"**
5. Executez **index.html**

Pour cloner AnimeRequester

1. **git clone https://github.com/gabidut/AnimeRequester.git**
2. Ouvrez le dossier **"AnimeRequester"**
3. Executez **index.html**
